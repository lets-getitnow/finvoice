## Decision brief

Before substantial work, fill this compact brief using evidence and qualitative tradeoffs; do not invent numerical priority weights. Read governing intent, current state and applicable execution requirements when routed by destination policy.

| Field | Required content |
| --- | --- |
| Decision | Exact comparison/experiment and the useful project choice it informs; what a negative result could save or change. |
| Alternatives | Strongest feasible competing actions, including stopping or deferring; current prerequisites, why this action is preferable now, and what would reverse the choice. |
| Discriminating result | Concrete findings for continue, revise, reject or inconclusive. For a repair: reusable mechanism, correctness evidence and what residual scope/cost uncertainty the pilot can resolve. |
| Validity | Dependencies from decision inputs through processing and measurement; distinguish demonstrated effect, plausible dependency and unknown materiality. Name remaining blockers to the exact comparison. |
| Budget and stop condition | Authorized bounded effort; time, money, complexity and owner attention. Distinguish measured cost, assumption-built estimate, configured bound and unknown. Define when to stop/reassess instead of automatically choosing another repair. |

For substantial evaluations, reference predeclared objectives, comparators, risk/minimum useful improvement, windows, costs/execution/data and advance/reject/inconclusive criteria in the execution specification. Use approved definitions where available. Mark missing required thresholds UNSET; do not use them as satisfied promotion criteria. A dependency task must name the experiment/decision it unlocks; a recurring blocker needs a new source, method or reason to expect progress.

Source availability, issue counts and prior effort alone do not justify priority. Incomplete evidence cannot prove irrelevance. A representative pilot does not establish a whole-program completion forecast. Explain the residual path without building a separate planning project. When governing policy permits sensitivity bounds, label assumptions and distinguish the question they inform from a validated result or acceptance gate. Keep scale illustrations separate from forecasts/thresholds, and one-time investigation opportunity cost separate from recurring program expense.
